# key2con
*What is key2con?*
An open-source Nintendo Switch CFW sysmodule/homebrew that lets you play games using a keyboard and mouse as a virtual controller.

# 🎮 Features
. Play any Switch game with USB keyboard & mouse
. Map any KB&M key/button to a gamepad buttons or sticks using the key2con Homebrew
. Experimental Gyro/R-Stick-as-mouse support

# 📝 Planned Features
. Better KB&M and Gamepad management
. Link a keyboard or mouse to a specific virtual gamepad (ex: Keyboard 2 = Virtual Pro Controller 2)
. An overlay cursor that can be moved on the Switch screen and used to simulate touchscreen input
. Bluetooth KB&M support (It probably won't happen.)
